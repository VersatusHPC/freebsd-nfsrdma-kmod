# Contributing

Bug reports and pull requests are welcome.

For bug reports, these details help us reproduce the problem:

- Module version.
- FreeBSD version and source revision.
- Kernel configuration.
- RDMA adapter model and firmware version.
- Client operating system and version.
- Steps to reproduce the problem.
- Relevant error messages or backtrace.

A short description of the change and how it was tested helps us review
pull requests.
